# CENTRONIC - Atendimento Virtual

Sistema de atendimento virtual integrado com WhatsApp e Telegram.

## 🚀 Funcionalidades

- Recebimento de mensagens WhatsApp
- Atendimento via Telegram (Admin)
- Dashboard de monitoramento
- Relatórios profissionais
- Envio de campanhas em massa

## 📋 Pré-requisitos

- Node.js 18+
- MongoDB Atlas
- Telegram Bot Token
- WhatsApp Web (escaneamento único)

## 🔧 Instalação

```bash
npm install
cp .env.example .env
# Edite .env com suas configurações
npm start
